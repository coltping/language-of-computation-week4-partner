# language-of-computation-week4-partner

**This repository holds partner work written by Claude (Anthropic's AI assistant), not by a student.**

Colt Pingilley was not assigned a classmate as a partner for MSAI-5523 Module 4, so Claude played "Student B". This repo holds the partner's side of the assignment:

- `week3/rules.md`: Student B's Module 3 rules, written separately as a second point of view for the Part 1 comparison.
- `rules.md`: the rules both partners agreed on, identical to Colt's.
- `ingest.py`: Student B's ingestion, written separately from the agreed `rules.md` (not copied from Colt's).
- `books.csv`, `books-batch2.csv`: the same two deliveries, byte for byte.
- `books.db`, `ingestion-log.json`: the result of running `ingest.py` on books.csv, books.csv again, and books-batch2.csv.
